# Tasarım ekranları

Kaynak: "Pati Dostu – Logo" tasarım tuvali (claude.ai). Her ekran 1440 px masaüstü veya 390 px mobil genişlikte, tam sayfa görüntüdür.

Notlar:
- Durumlu ekranlarda (ör. *İlan ver YZ ile 1: fotoğraf*) tüm durumlar alt alta görünür; gerçek sayfada yalnızca biri gösterilir.
- Pencere ekranlarında (randevu, yorum, paylaşım…) arkadaki sayfa karartılmış hâlde görünür; kodda bunlar `Dialog` (masaüstü) / `Drawer` (mobil) olur.
- Renk, ölçü ve bileşen karşılıkları için `apps/web/app/globals.css` ve `docs/proje-taslagi.md` › *Tasarım sistemi ve bileşenler*.
